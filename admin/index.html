Importar base antiga

Exporte a lista de compradores no painel da Hotmart (Vendas → Exportar) e cole aqui, uma linha por pessoa, no formato: email, nome, telefone, nome do ebook. Isso libera o acesso pra quem já comprou antes do app existir — não precisa esperar uma compra nova.

Configurar o Webhook na Hotmart

Siga esses passos uma vez só, no painel da Hotmart:

  1. Entre em Ferramentas → Webhook (dentro da área de Produtor).
  2. Clique em Criar Webhook.
  3. Cole essa URL no campo de endereço: carregando...
  4. Marque o evento Compra Aprovada (PURCHASE_APPROVED).
  5. Copie o código "Hottok" gerado e me envie — eu configuro no servidor.
  6. Selecione se o webhook vale pra todos os produtos ou escolha os 6 ebooks manualmente.

Depois disso, toda compra aprovada libera o acesso automaticamente — não precisa fazer mais nada.
